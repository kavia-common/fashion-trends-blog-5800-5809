# Local Development and Running Instructions

## Prerequisites

- [Node.js](https://nodejs.org/) (v16 or above recommended)
- [npm](https://www.npmjs.com/) (Installed with Node.js)

## Setup

1. **Install Dependencies**
   ```sh
   npm install
   ```

2. **Start the Development Preview Server**
   ```sh
   npm start
   ```
   This will run the app in development mode at:  
   [http://localhost:3000](http://localhost:3000)

3. **Make Code Changes**
   - Code edits will hot reload the app automatically.

4. **Testing (Optional)**
   ```sh
   npm test
   ```
   This launches the sample test runner (see `App.test.js`).  
   _Note: No custom tests are included by default._

## Folder for Docs

- All in-depth documentation for developers is located in the `docs/` folder.
